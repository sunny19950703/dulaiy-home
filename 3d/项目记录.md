# 度拉家居 3D 户型示例 · 项目记录

- 日期：2026-09-30
- 用途：给度拉家居（原柏丽家居）展示"户型图 → 可操作 3D 方案"的样子，配合《度拉家居 AI 与内容优化建议》第四部分第 2 项。
- 文件：`index.html` + `lib\`（three.js r147，MIT 许可，LICENSE 在 lib 里）。纯本地网页，不联网。
- 打开方式：双击 index.html（Edge/Chrome 都可以）；或放到 GitHub Pages 等静态空间用链接打开。
- 户型：自己画的约 180㎡ 示例大平层（大横厅、中西厨、三房一书房、玄关、公卫、衣帽间），不是度拉的真实户型。
- 功能：2D 平面（面积、尺寸、开门线）、摆家具（13 种，拖动/旋转/删除）、拆改墙体（承重墙不可拆、可恢复）、测量、换地面（5 种材质）、一键 3D 俯瞰（墙体升起动画）、进屋漫游（键盘/屏幕按钮、防穿墙）、平板竖屏布局。
- 没做（正式版要做）：上传户型图自动识别（按钮只是提示）、门窗编辑、方案保存/分享、真实家具模型和材质库。
- 参考：X 上 @akokoi1 的 floorplan-3d 帖子（该项目没有开源许可证，未使用其代码，本页从零编写）。
- 测试：2026-09-30 桌面 1440 宽、平板 768×1024 检查过，控制台无报错。
